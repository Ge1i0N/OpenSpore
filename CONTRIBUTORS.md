## GitHub attribution note

Adding a name here does **not** add a person to GitHub's contributor graph. GitHub attributes a
commit when it is present in the repository's history and its author/committer email is linked to
that GitHub account (or when a pull request is merged with the corresponding attribution). For a
real contribution, use a pull request or a commit authored with the contributor's account-linked
email; a `Co-authored-by:` trailer can preserve joint authorship. The user controls the eventual
push/merge through GitHub Desktop.
